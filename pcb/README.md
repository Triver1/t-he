# TOTEM-HE PCB (Ergogen)

Hall-effect version of TOTEM's layout at MX spacing, one PCB per half. Generated by Ergogen, routed by hand in KiCad.

## Build

```bash
./build.sh
```

`gen_config.py` writes `config.yaml` from `../totem_geometry.scad` (key positions, holes, XIAO, TRRS) and the case's PCB outline, then Ergogen runs in a `node:20` container. Output per half in `out/<side>/`: `pcbs/totem_he_<side>.kicad_pcb` (unrouted), `outlines/board.dxf`, `outlines/plate.dxf` (14 mm switch cutouts). `pcbfit.py <scratch>` checks the result against the case.

## Electronics

Same scheme as Boardloaf-HE. All parts sit on the switch side, so the underside is flat and the PCB is the case base.

| Part | Qty per half | Notes |
| --- | --- | --- |
| SLSS49E-3 (LCSC C2904393) linear hall sensor, SOT-23 | 19 | Under each stem magnet. Pin 1 VDD, 2 GND, 3 Vout per the datasheet (`sensor_pins` in `switch_he.js`). Boardloaf-HE's symbol swaps 2 and 3 |
| 100 nF 0805 | 22 | One per sensor and per mux, hand-solder pads |
| 74HC4051 SOIC-16, hand-solder pads | 3 | U_A pinky, outer and ring keys; U_B middle, index, thumb 1 and 2; U_C inner keys and thumb 3 |
| XIAO RP2040 | 1 | On top of the board at the outer edge, soldered flat on its castellations; USB-C overhangs the edge |
| PJ-320A TRRS | 1 | Tip VCC, ring 1 TX, ring 2 RX, sleeve GND |
| M2 plated holes | 4 | Case screws |

XIAO pins: D0, D1, D2 read mux A, B, C (ADC0..2). D4, D5, D8 drive the shared select lines SEL0..2. D6 TX and D7 RX go to the TRRS; both halves are wired the same, so the firmware swaps TX and RX on one half. 3V3 powers the sensors and feeds the other half over the TRRS, like TOTEM's wired build.

## Footprints

`footprints/switch_he.js`, `mux_4051.js`, `xiao_rp2040.js` are this project's. `footprints/ceoloide/` holds the TRRS and mounting hole from ceoloide/ergogen-footprints (MIT and CC BY-NC-SA 4.0).

## Routing

Per half, after `./build.sh`:

```bash
docker run --rm -v "$PWD":/w -w /w kicad/kicad:8.0 python3 route.py prep out/left/pcbs/totem_he_left.kicad_pcb routed/left_prep.kicad_pcb routed/left.dsn
docker run --rm -v "$PWD/routed":/w --entrypoint java ghcr.io/freerouting/freerouting:latest -jar /app/freerouting-executable.jar --gui-enabled=false -de /w/left.dsn -do /w/left.ses -mp 40
./finish.sh left
```

`finish.sh` imports the session, appends GND fills on both layers (`addzones.py`), fills them, writes the project file with the design rules (`mkpro.py`) and runs DRC. Result: `routed/totem_he_<side>.kicad_pcb` plus `.kicad_pro`; open the `.kicad_pro` so KiCad picks up the rules. Rules: 0.25 mm tracks, 0.2 mm clearance, 0.6 / 0.3 vias, 0.25 mm to the board edge (JLCPCB allows 0.127 / 0.127 / 0.3).

Both halves route completely with Freerouting (0 unrouted, 0 violations). DRC is clean apart from one warning on the left half, a silk label of the XIAO clipped by solder mask. `pcbfit.py` checks the generated boards against the case geometry.

Freerouting will not route to a pad closer than about 0.5 mm to the board edge. That is why the XIAO sits on top of the board with no cutout; earlier revisions with the XIAO sunk in a cutout left every XIAO net unrouted.
